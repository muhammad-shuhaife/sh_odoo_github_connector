From connection to clone in three steps

1. Connect your account

Open Settings → GitHub Connector. Paste your token and click Connect & Sync.

2. Choose a repository path

Open GitHub → Repositories. Set the full Clone Path and choose a branch if needed.

3. Clone, then pull updates

Click Clone Repository once. Use Pull Latest for subsequent updates.

Where do I get the access token?

In GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Select your repositories, grant the permissions you need, generate the token, and paste it into Odoo Settings.

Your paths. Your branches.

The Clone Path is the complete repository folder on the machine hosting Odoo. For example:

/opt/odoo/custom_addons/my_repository

Odoo’s operating-system user needs write access to the destination, and Git must be installed. Clone and pull execute directly within the request; large repositories may need a terminal.

Clear boundaries

Does pulling install an Odoo module?
No. Clone and Pull change source files. Add the correct directory to addons_path, then install or upgrade modules separately.

Who can change a repository?
Connector administrators can clone, pull and make GitHub changes. Operators can refresh data; viewers can read it.

Do I need a worker or workflow file?
No. This version connects directly to GitHub and runs local Git commands from Odoo.
